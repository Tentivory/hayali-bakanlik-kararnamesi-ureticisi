# T.C. Hayali Bakanlık Kararname Üreticisi

> "Devletin görünmeyen ama çok çalışan kolu."

Bu yazılım, gerçek hayatta üretilemeyecek kadar önemli kararname metinlerini
saniyeler içinde basar. Hiçbir bakanlık onayına ihtiyaç duymaz çünkü bakanlık
zaten hayalidir.

## Neden var?

Çünkü evrak işleri durmasın diye. Çünkü ciddiyet boşluk kabul etmez.
Çünkü bir gün birisi "bu resmi mi?" diye sorduğunda "hayır, daha resmi"
diyebilelim.

## Kurulum

```bash
python3 kararname.py
```

Başka bir şey kurmanıza gerek yok. Python varsa devlet de vardır.

## Örnek çıktı

Program her çalıştırıldığında yepyeni, birbirinden bağımsız ve hukuken
bağlayıcı olmayan (ama duygusal olarak bağlayıcı) bir kararname üretir.

## Sorumluluk reddi

- Bu repo bir şaka değildir. Şaka gibi duruyorsa bu sizin sorunuzdur.
- Üretilen kararnameler yargı organlarınca tanınmaz.
- Tanınırsa haber verin, sürüm notuna ekleriz.
